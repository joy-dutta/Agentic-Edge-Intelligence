# Repository Layout

```text
.
|-- artifacts/tables/       Released CSV and JSON result tables
|-- checkpoints/            Frozen IDQN checkpoints and training manifest
|-- configs/                Frozen protocols, prompts, seeds, policies, and budgets
|-- data/processed/         Confirmatory run-level CSV and Parquet data
|-- docs/                   Technical and reproducibility documentation
|-- network/                MQTT broker configuration
|-- patches/                Deterministic RESCO patch
|-- scenarios/              Scenario provenance documentation
|-- scripts/                Execution, audit, analysis, and verification commands
|-- src/ojcoms_poc/         Experiment implementation
|-- tests/                  Offline unit and integration tests
|-- Dockerfile.release      Public reproducibility container
|-- Dockerfile.experiment   Container definition frozen with the completed protocol
|-- docker-compose.yml      Experiment and network-harness services
|-- requirements*.lock      Pinned dependency sets
`-- CITATION.cff            Software citation metadata
```

## Generated but Not Published

The following paths are created locally and ignored:

- `external/RESCO`: upstream scenario checkout at the pinned commit.
- `artifacts/raw`: per-run summaries and decision/API audit logs.
- `artifacts/logs`: budget ledger and process logs.
- `artifacts/pcap`: network packet captures.
- `artifacts/network_tls`: disposable test certificates and keys.
- `artifacts/figures`: optional analysis plots generated by local commands.
- `configs/platform_budget_gate.json`: user-created account-limit record.
- `configs/api_contract_gate.json`: one-call model/schema verification record.
- `.env*` and `.secrets`: local secret material, which should never be committed.

The public package intentionally contains no manuscript and no publication figure. Released results are provided as machine-readable tables.
