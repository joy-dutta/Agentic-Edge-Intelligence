# Controller Checkpoints

This folder contains the frozen reinforcement-learning checkpoint used only for the IDQN sensitivity study. IDQN is not one of the seven configurations in the main confirmatory matrix.

The complete checkpoint set is under [`idqn_100episodes/`](idqn_100episodes/README.md). Readers interested only in the main proof of concept can skip this folder. To evaluate the checkpoint, install `requirements/idqn.lock` and follow the checkpoint README.
